# Fix "document is not defined" Error in PDF Ticket Generation

## Problem
When accessing `/api/bookings/[id]/ticket?format=pdf`, the API returns `{"error":"document is not defined"}`. This occurs because the `generateBarcodeSVG` function in `lib/ticket.ts` uses `document.createElement('canvas')`, which is a browser DOM API not available in Node.js server-side environment.

## Root Cause
The barcode generation code relies on JsBarcode library creating a canvas element using `document`, but server-side PDF generation runs in Node.js without a DOM.

## Solution
Install the `canvas` package to provide Node.js canvas API and modify the barcode generation to use server-side canvas instead of browser document.

## Steps
1. Install the `canvas` package: `npm install canvas`
2. Update `lib/ticket.ts`:
   - Import `createCanvas` from 'canvas'
   - Modify `generateBarcodeSVG` to use `createCanvas` instead of `document.createElement('canvas')`
3. Test the PDF generation endpoint to ensure it works without errors

## Verification
After implementation, accessing the PDF ticket URL should return a valid PDF file instead of the error.
